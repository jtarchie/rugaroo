# Decision 436

**Rule:** The runtime helpers in `prelude/go` are fuzzed by differential comparison with MRI: one compiled driver program per area reads hex-encoded cases from stdin, a Go test diffs its output with `ruby`'s on the same cases, and the lane runs only under `RUGAROO_FUZZ_DIFF=1`.

2026-11-03. `go test -fuzz` cannot reach `prelude/go`: every file is `//go:build rugaroo_prelude` and names generated types (`String`, `Array[T]`, ...) that exist only as the vet-only stubs of decision 154, so importing a helper tests a copy. The compiler side is fuzzed in-process (`FuzzCompile`, `FuzzRxFast`, `FuzzBacktrack`, `FuzzGoLocalName`, `FuzzParseLiteralFormat`); the runtime side needs MRI as the oracle, the way TestRun and TestMinitest already use it.

- **Driver** `testdata/fuzz/<area>.rb` (not under `testdata/run`, so TestRun does not also take it): reads lines `op<TAB>hex<TAB>hex...` (strings hex-encoded so any bytes pass unescaped; Floats as 64-bit hex bits so NaN, -0.0, subnormals and rounding boundaries are reachable), runs each in `begin/rescue Exception`, prints `result.inspect` or `EXC ClassName message`. Typed `#:` methods, and it must run on MRI unchanged.
- **One program per area** (format/float/pack/string first; then json, bignum under `--int-overflow=promote`; time with TZ pinned and regexp with a skip list last). A combined program hits decision 81's Dyn-wrapper build blowup.
- **Go test** compiles each driver once (`goBuild`), generates a seeded case list with grammar-aware generators, runs `ruby` and the binary once each, diffs line by line, and prints the case plus both outputs. MRI output rides the existing oracle cache. A failing case is kept in `testdata/fuzz/corpus/<area>.txt` and replayed by every plain `go test`; a deliberate divergence (decision 20's message wording) goes in a per-area skip list with its reason.
- **Gate:** `RUGAROO_FUZZ_DIFF=1` (case count in `RUGAROO_FUZZ_N`) so the ~6 min suite is unchanged; only the replayed corpus runs by default.
- **Properties** that need no MRI (`unpack(pack(x)) == x`, `Float(x.to_s) == x`, `JSON.parse(JSON.generate(f)) == f`) live in the driver beside the differential ops. A Go runtime panic surfacing as an exception where MRI returns a value is a finding; `RUGAROO_GO_STACK=1` (decision 324) supplies the stack.
- **Not now:** a `FuzzDiff` wrapper feeding persistent MRI and binary processes, so `go test -fuzz` mutates and stores the corpus. Coverage guidance cannot see the child binary, so it would be mutation-only.

Candidates, by expected yield: Float formatting (`format.go` dtoa), sprintf directives, pack/unpack, String tr/succ/split/Integer()/Float(), JSON (Grisu2, parser), bignum and the overflow lanes, Time, regexp.

# Decision 466

**Rule:** In an inference round, the untyped result of a call that passes a real type to every from-use parameter its method still has untyped is provisional (it widens neither a local, a reassigned gem parameter nor a destructured target), unless that method has already returned untyped with its parameters typed.

**Provisional results at the call** (amends decisions 241, 358, 383; 2026-11-15). *See also decisions 146, 444.*

Decision 358 keeps a round's untyped result from widening a local while the callee awaits its parameters. Two holes left the parser gem's `Source::Buffer#source` untyped, and with it the lexer's code points, every `tok`, and 300 call sites:

```ruby
def source=(input)
  input = input.dup if input.frozen?
  input = self.class.reencode_string(input)   # reencode_string(input) returns what it is given
  self.raw_source = input
end
```

- **The deadlock.** Round 1: `source=`'s own `input` is untyped, so `reencode_string` is called with an untyped value and no call types its parameter. Round 2: `input` is a String, but `reencode_string`'s parameter was typed by nothing in round 1, so 358 no longer awaits it (`inference.none`); its untyped result is final, `widenParam` (decision 241) widens `input` to untyped, the body's later passes pass an untyped `input`, and round 3 is round 2 again.
- **The rule.** `typedThisCall`: the body records the from-use parameters it passed a real type this round (`fctx.typedUse`, set in `noteUse`). A call whose method's untyped from-use parameters were all passed one will have them typed by the next round, so its untyped result is provisional now, whatever the previous round concluded. `widenParam` skips a provisional value as `noteReassign` does, and `genMultiWrite` marks the targets of a provisional value's destructuring (`p, state = @strings.advance(p)`).
- **No flip.** A method that still returns untyped once its from-use parameters are all typed is recorded (`inference.hardAny`, by its first such parameter): its result is never provisional again, so a caller cannot alternate between the two readings round after round.
- **Measured.** A 50-line copy of `Source::Buffer`: `@source` untyped with 15 dynamic calls → `String?` with none. The parser gem under `-trace` (21 files): `Buffer@source` → `String?`, `@lines` → `Array[String]?`, `Lexer@source_pts` → `Array[Integer]?`; dynamic-call warnings 3,427 → 3,377. The run time does not move on its own (7,979M → 7,945M instructions): the lexer's position and state stay untyped through stored lambdas (`p = @num_xfrm.call(digits, p)`), see "Not done".
- **Not done.** (1) A stored lambda's parameters and result are untyped when the ivar holding it is assigned from other ivars (`@num_xfrm = @emit_integer`); with the lexer's 25 ivars and 5 methods given signatures by hand, the same program runs 2,470M instructions instead of 7,945M. (2) A constant Array of mixed element classes read by position (racc's `Racc_arg`, destructured in `_racc_do_reduce`) has untyped elements; its tables are then indexed dynamically (half of the remaining parse time).
- **Proof:** `testdata/run/gem_lenient/ragelish.rb` (`Buf`), compared with MRI by `TestRun/gem_lenient`.

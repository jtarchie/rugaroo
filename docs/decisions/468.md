# Decision 468

**Rule:** `rbClassOf` (an untyped value's `class`) first switches on the value's class ID to its root class's case, so an object meets one interface test instead of every root's in order.

**`class` of an untyped value by class ID** (amends decision 212; 2026-11-15). *See also decisions 213, 354.*

`rbClassOf` was one type switch: the core types, then a case per struct-class root (`case RuboCop_Cop_BaseI: return v._ClassOf().(ClassI)`), 90 interface cases in the compiled rubocop. Go tests a type switch's interface cases in order, and the first time a concrete type meets an interface it builds that pair's method table (`runtime.getitab` → `itabInit`), matched or not, walking the type's methods. An object whose root is the 90th case paid for 89 tables it does not have, once per class: rubocop asks `cop.class` of each of its 600 cops while it picks the relevant ones, and `runtime.interfaceSwitch` under `rbClassOf` was 15% of its start-up (Linux profile, a 2-line input).

- **The pre-switch.** `emitClassOfByID`: `if id, ok := a.(interface{ _ClassID() int }); ok { switch id._ClassID() { case <the IDs of a root's classes>: if v, ok := a.(RootI); ok { return v._ClassOf().(ClassI) } ... } }`, the shape the dispatchers' arms have (`emitDynArms`). A switch on an integer is a binary search; the object then meets its own root's interface only. The class is still read through `_ClassOf()`, so an object carrying a run-time class (`rbCls_`) answers it.
- **What it covers:** classes whose root is a plain struct class (not generic, not a value type, not universal), exactly the roots the old switch gave a case to. Everything else (core values, class objects, Struct, Data, Proc) falls through to the switch as before.
- **Measured** (instructions retired, `GOMAXPROCS=1`, compiled rubocop, each equal to MRI's output): a 2-line file about 3,100M → about 2,400M over four runs each (the collector moves a run by ±5%; MRI 5,809M); 20 files 14,891M → 13,977M; 60 files 22,324M → 21,204M.
- **Proof:** every `class`, `is_a?` and `instance_of?` of an untyped value in `testdata/` goes through it (`TestMinitest/class`, `object`, `module`, `struct`, `exception`; `TestRun/gem_lenient`).

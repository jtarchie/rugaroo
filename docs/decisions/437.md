# Decision 437

**Rule:** `rugaroo build`, `run` and `test` compile without DWARF (`-gcflags=-dwarf=false -ldflags=-w`) unless `-debug`; a user `-gcflags` joins the default.

**No debug info in user builds** (#97; 2026-11-11). *See also decision 88* (the test builds already dropped DWARF).
Nothing in a built program reads DWARF: `RUGAROO_BACKTRACE=1` (decision
178), Go panic traces and `runtime.Callers` read the pclntab, which
`-w` keeps (`-s` would drop the symbol table; it is not used). DWARF is
only for a debugger stepping through the generated Go, so `-debug`
brings it back.
- **Composition.** go build keeps the last `-gcflags` that matches a
  package, so a plain user `-gcflags=-e` becomes `-gcflags=-dwarf=false
  -e`; a pattern one (`all=-N -l`) is passed as its own flag after the
  default and wins for the packages it names, as the user asked.
- **Measured** (2026-11-11, darwin arm64, a fresh `main.go` each so the
  package compiles, `/usr/bin/time -l go build -trimpath`):

  | program | wall | peak RSS | binary |
  |---|---|---|---|
  | `005_word_count` | 0.59 → 0.52 s | 156 → 134 MB | 3 → 2 MB |
  | `064_observable` | 3.68 → 1.90 s | 454 → 393 MB | 6 → 4 MB |
  | `116_cuba_web` | 10.03 → 7.30 s | 1,650 → 1,244 MB | 18 → 14 MB |

  `TestCompileCost` already builds with `-dwarf=false`, so it does not
  show the change.
- **Proof:** `TestUncaughtFullReport` (cmd/rugaroo) reads a default
  build's backtrace with Ruby `file:line` and checks the binary has no
  DWARF while a `-debug` one does; `TestBuildFlags` pins the
  composition.

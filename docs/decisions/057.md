# Decision 57

**Rule:** Index op-assigns evaluate receiver and index once, then call `[]`/`[]=`; several block params over an Array element splat it, each `T?`.

Index assignments `h[k] ||= v` and `a[i] op= v` evaluate the receiver
and index once, then call `[]` and `[]=` as Ruby does (`||=` writes
only when `[]` gave nil or false). A block taking several params over
an `Array[T]` element splats it, as Ruby does for any yielded Array:
each param is `T?`, nil past the end (tuples keep their exact
element types) ([example 50](../../examples/050_format_regexp/main.rb)).

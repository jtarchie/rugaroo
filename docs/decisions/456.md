# Decision 456

**Rule:** A proc or lambda literal with keyword (`k:`, `k: lit`, `**kw`) or `&b` parameters, assigned once to a local that is only ever called (`.call`, `.()`, `.yield`, `[]`, `===`) with its required positionals, literal-Symbol keywords and at most a block, is compiled as a Proc of positional parameters: each call passes the keywords by position (an omitted one its literal default, a missing required one MRI's ArgumentError, the rest as `**kw`'s Hash) and the block as a proc (or nil); any other use keeps the compile error, which now says so.

**Proc literals with keyword or block parameters** (#157, #114's follow-up; amends decisions 13 and 369; 2026-11-13).

A Proc is a Go function value whose type (`TFunc`) lists positional parameters only, so `proc { |a, &b| }` and `->(x, by: 2) { }` were "unsupported block parameter form". Giving `TFunc` keyword and block slots would reach every Proc type, its unions, joins and the inference cache (decision 430); a local that is only called needs none of that: its calls are all in view.

- **Lowering** (`lowerProcParams`, parse time, per frame: the program and each def body, through its blocks). The literal's keywords, then `**kw`, then `&b` become required positionals after its own and before its rest (`->(*a, **kw)` is `->(kw, *a)`); each call is rewritten to match. A keyword's default is copied to calls that omit it, so it must be a literal (Integer, Float, String, Symbol, nil, true, false); a call that passes a splat, an unknown keyword, or the wrong number of positionals leaves the literal unlowered.
- **What differs from MRI:** `Proc#parameters` and `#arity` of such a Proc report the positional form; a keyword's non-literal default is not supported here.
- **Inference fix found on the way.** A parameter whose uses are `nil` and a value still untyped (here: a block passed as an untyped proc) joined to `NilClass`, so `b ? b.call(a) : :none` was folded to its else branch. Such a join now leaves the parameter untyped (`joinUses`).
- **Proof:** `testdata/test/control_test.rb` `ProcParamsTest` (optional, required and `**kw` keywords, `&b` with and without a block) against MRI; `testdata/errors/control.txtar` `proc_block_param_escapes`.

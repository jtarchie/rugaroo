# Decision 476

**Rule:** `RUGAROO_UNTYPED_REPORT` ranks the roots of untyped receivers by dynamic-call sites, each with the reason recorded where the compiler decided it (debug only).

**`RUGAROO_UNTYPED_REPORT=1` (stderr) or `=path` (a file) prints one report of why a program compiles to dynamic dispatch** (builds on 283 and 318; 2026-11-21). Finding a gem's untyped roots took two runs per root: `RUGAROO_UNTYPED_WHY` to name it, then `RUGAROO_INFER_USES` and `RUGAROO_INFER_DEBUG` to see what made it untyped. The report does both in one compile, after spinel's `--emit-types` and `--warn-widen`:

- **Sites.** Every `dynamic call` warning is one site (gem files' too, whether or not `RUGAROO_GEM_WARNINGS` prints them). A site is an entry in `Compiler.Warnings` behind a marker prefix, so the warnings' own dedup and a discarded pass's `dropWarnings` apply to it; `shownWarnings` leaves the entries out of what the compile returns.
- **Roots.** `untypedWhy` returns a `why`: the text `RUGAROO_UNTYPED_WHY` prints, unchanged, and an `untypedRoot` (kind, name, position, and the key, method or ivar its reason hangs on). A return whose body's value is untyped, and an ivar whose first write stores an untyped value, pass their value's root on (the report's `through:` line names them); they are roots themselves only when nothing upstream is one. An untyped element of a typed container (`Hash[Symbol, untyped]`) is charged to the container's root, marked as such. An attr reader's value is its ivar's root, a gem module's ivar the one its includer keeps, and an operator write (`x.depth += 1`, `h[k] ||= v`) the root of what it reads.
- **Reasons** are recorded at the decision, never rebuilt:
  - a parameter typed from use (and a lambda's, and a method's yields): the rule of `unknownRule`, `useType`, `gemUseType`, `growState` or `settleRound` that fired in the last round, with that round's uses by type, how many calls passed each, where the first is, and for an untyped argument the root of its value (`inference.why`). Under `RUGAROO_INFER_UNKNOWN` the last round is a resolved one, so the reason is the resolved phase's; a type the state kept from an earlier round says so, with that round's reason. A final pass that widens a parameter (decision 444) says so too.
  - an ivar: the write that declared it and what it stored, the write that widened it (decisions 331, 416, 458), or the rule that declared it untyped (decisions 147, 160, 169, 183, 220, 392, 445), with file and line (`Compiler.ivarNotes`). An open container (`@xs = []`) also says what the last discovery walk saw written to it, and the element typing `refineIvars` tried and dropped, when it did. An ivar a module or superclass reads by name (decisions 324, 330) is a root of its own kind: the read is untyped whatever the ivar's type.
  - a return: `inferRet`'s `retWhy` (the two types that did not join, recursion, an abstract body). The places of the return expressions are not recorded.
  - a signature: its text and line; the prelude's, its file and line.
  - a parameter widened by reassignment: the two types.
- **Not recorded** (the report says so): a local set by a non-plain write or holding a container of untyped, a constant, `self`, an expression that is its own root (a mixed Hash literal, an `if`, a `case`, `a || b`), a typed ivar read as untyped (a nilable gem ivar), the places of a return's expressions, the `.rbs` file behind an attribute's signature, and why a dropped `refineIvars` typing did not compile.

The compile runs cold under the variable (the inference cache keeps types, not reasons). With it unset nothing is recorded and the generated Go and the warnings are byte-identical (checked on `testdata/run/gem_inference.rb`, liquid and kramdown, both lanes). `TestUntypedReport` runs the fixture in both lanes: the report's site count is the warnings' count, and every site is under a root.

# Decision 488

**Rule:** An Array past 256 elements at least doubles its storage when a push fills it, and a prelude result whose final length is known is allocated at that length.

**Runtime hotspots from the benchmark profiles** (2026-11-22). *See also decisions 377, 387, 391, 403.* A profiling pass over the 24 programs in `benchmarks/` (merged CPU profiles, linux/arm64) found costs that are not benchmark-specific: each one is in code every program reaches. Each fix was tried first by hand in a `-work` build's main.go, then made in the compiler or prelude.

- **Array growth.** Go's `append` grows a slice past 256 elements by about 1.25x, so an Array built by `<<`/`push` copies about 4x its final size, and its last backing arrays sit in the heap together. `Array#<<` and `Array#push` (`prelude/array.rb`) first extend a full Array of 256 or more elements with `append(s, make([]E, len(s))...)[:len(s)]` (Go compiles append-of-make to one growth with no temporary; growslice then gives at least twice the capacity), and `inlinePush` (`internal/compiler/inline_idxset.go`, decision 391) writes the same test at a site it inlines; `preludeAppend` now recognises the four-statement body. `slices.Grow` does the same, but is generic: each element type instantiates it, one more compiled function per type (TestCompileCost's 116_cuba_web went 33,441 to 33,450). The extension is a new backing array, so an Array that shared storage could not see another's append (none does: `dup`, slices and `+` copy). The frozen check still comes first.
- **Presized results.** A prelude method whose result length is known before the loop that fills it allocates that length: `Array#reverse`, `#+`, the untyped copy `_to_any`, `Range#to_a` (an Integer range's length, capped at 2^20 like `Range#map`), `String#lines`, `#split` (each form), `#codepoints`, `Enumerable#sort_by` (its key list takes an Array receiver's size, its result the key list's) and `#sort`, `Enumerator#with_index`/`#each_with_index` over an Array, `Array#sample(n, random:)`, `Integer#digits` (now a Go body that counts the digits first), and `rbArgsCat` (the splat-joining helper). Results filtered as they are built (`select`, `-`, `&`, `uniq`, `compact`) keep growing: their length is not known.
- **Not done** (same profile): `Mutex#synchronize`'s body, a thread's start-stack capture, Symbol Hash keys.

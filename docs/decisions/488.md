# Decision 488

**Rule:** An Array past 256 elements at least doubles its storage when a push fills it, a prelude result whose final length is known is allocated at that length, an interpolation of literals, Strings and Integers with the prelude's `to_s` is built in one buffer, `x == nil` on a `C?` is a nil test when every class an object of `C` can be keeps Object#==, and the current thread's root Fiber is looked up before one is made.

**Runtime hotspots from the benchmark profiles** (2026-11-22). *See also decisions 377, 387, 391, 403, 489 (interpolation parts read in order).* A profiling pass over the 24 programs in `benchmarks/` (merged CPU profiles, linux/arm64) found costs that are not benchmark-specific: each one is in code every program reaches. Each fix was tried first by hand in a `-work` build's main.go, then made in the compiler or prelude.

- **Array growth.** Go's `append` grows a slice past 256 elements by about 1.25x, so an Array built by `<<`/`push` copies about 4x its final size, and its last backing arrays sit in the heap together. `Array#<<` and `Array#push` (`prelude/array.rb`) first extend a full Array of 256 or more elements with `append(s, make([]E, len(s))...)[:len(s)]` (Go compiles append-of-make to one growth with no temporary; growslice then gives at least twice the capacity), and `inlinePush` (`internal/compiler/inline_idxset.go`, decision 391) writes the same test at a site it inlines; `preludeAppend` now recognises the four-statement body. `slices.Grow` does the same, but is generic: each element type instantiates it, one more compiled function per type (TestCompileCost's 116_cuba_web went 33,441 to 33,450). The extension is a new backing array, so an Array that shared storage could not see another's append (none does: `dup`, slices and `+` copy). The frozen check still comes first.
- **Presized results.** A prelude method whose result length is known before the loop that fills it allocates that length: `Array#reverse`, `#+`, the untyped copy `_to_any`, `Range#to_a` (an Integer range's length, capped at 2^20 like `Range#map`), `String#lines`, `#split` (each form), `#codepoints`, `Enumerable#sort_by` (its key list takes an Array receiver's size, its result the key list's) and `#sort`, `Enumerator#with_index`/`#each_with_index` over an Array, `Array#sample(n, random:)`, `Integer#digits` (now a Go body that counts the digits first), and `rbArgsCat` (the splat-joining helper). Results filtered as they are built (`select`, `-`, `&`, `uniq`, `compact`) keep growing: their length is not known.
- **Integer interpolation.** `"item-#{i}-#{i * 2}"` was `"item-" + Integer.ToS(i) + "-" + ...`: one String per Integer, then the concatenation. When every part is a literal, a String, or an Integer whose `to_s` compiled to the prelude's own (`plainIntToS`: no program or gem redefines `Integer#to_s`, and not under `--int-overflow=promote`, where an Integer may be a Bignum), `interpAppend` (`internal/compiler/expr_literal.go`) emits statements that append each part into a 64-byte stack array (`strconv.AppendInt` for an Integer), after any statements the parts themselves emitted, and the value is `String(buf)`: one copy. Parts keep their order: an emitted statement turns an earlier argument of the same call into a temporary, as for any code the compiler hoists. The result is a new String as the `+` chain's was (an Integer part is never empty, so it is never another String's bytes), with the same encoding and frozen facts. Floats, other classes and a class with its own `to_s` keep the old path. A first part that is a String value also keeps it: `rbConcat` extends a buffer `rbStrCat` made in place, which a `s = "#{s}#{i}"` loop relies on. Two other shapes were tried: an immediately called closure at the site (111M instructions on `benchmarks/strings`), which adds a function per site that Go does not inline; and a variadic prelude helper `rbInterp(rbIP{...}, ...)` (123M), which adds one function to every program that interpolates an Integer. The emitted statements add none (108M).
- **`x == nil`.** On a `C?` receiver, `x == nil` (and `x != nil`, which is `!(x == nil)`) went through `rbEq[any](rbPtrAny(x), nil)`. When the argument is the `nil` literal and every class at or below `C` (closed world, `classesBelow`) resolves `==` to Object#== from the prelude (`identityEqBelow`, `internal/compiler/expr_union.go`), it is `x == nil` in Go. Any other `==` keeps the call, because MRI calls it with nil: a program's own, an inherited one, a subclass's, or a prelude one other than Object's (Comparable's calls `<=>`, Delegator's forwards). `nil == x` is NilClass#== and unchanged.
- **Root Fiber.** `rbCurrentFiber` called `rbRootFibers.LoadOrStore(t, &Fiber{...})`, which builds the Fiber on every call from a thread's root fiber (every `Fiber#resume` from it). It `Load`s first and stores only on a miss.
- **Not done** (same profile): `Mutex#synchronize`'s body, a thread's start-stack capture, Symbol Hash keys.
- **Measured** (instructions retired, `GOMAXPROCS=1`, macOS arm64, two runs each, before/after; outputs equal MRI's): array 152M/158M to 148M/153M, peak memory 30 to 19 MB; objects 207M/212M to 202M/207M, peak 23 to 15 MB; blocks 389M/393M to 374M/379M, peak 34 to 15 MB; collections 1,382M/1,379M to 932M/939M (-32%), peak 57-61 to 36 MB; strings 159M/164M to 108M/113M; format 1,379M/1,382M to 1,264M/1,275M; binary_trees 57M/62M to 44M/49M; fiber 591M/601M to 475M/480M, peak 34 to 10 MB; json 1,483M to 1,483M, kramdown 4,015M/4,123M to 4,058M/4,088M and liquid 1,720M/1,725M to 1,721M/1,740M, within their run-to-run spread.
- **Cost:** TestCompileCost compiled functions unchanged (005_word_count 2,088, 064_observable 8,276, 116_cuba_web 33,441).
- **Proof:** `array_test.rb` `ArrayGrowthTest` (pushes past 256, 512 and 7,500 elements with reads, `dup`s taken at the boundaries and appended to afterwards, a frozen Array's FrozenError from `<<` and `push`; each presized method on empty, one-element and 3,000-element receivers; `digits`' errors); `string_test.rb` `StringInterpIntTest` (negative, zero, the 64-bit bounds, nesting, a class's own `to_s`, a leading String, a `"#{s}#{k}"` build loop, a binary String interpolated, `lines`/`split`/`codepoints`); `testdata/run/string_interp_own_int_to_s.rb` (a program's own `Integer#to_s` is still called); `object_test.rb` `NilEqTest` (`x == nil`, `x != nil`, `nil == x` on a plain class, on a class with its own `==` whose call count is checked, on its subclass, and on a base class whose subclass defines `==`); `fiber_test.rb` `FiberRootReuseTest` (a Fiber resumed 1,000 times from the main thread and from four Threads).

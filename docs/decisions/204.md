# Decision 204

**Rule:** String evals and block `class_eval`/`module_eval` boot ran on a named module compile into its body; other evals are compile errors.

**String and block evals from boot** (amends 161). `eval`,
`class_eval`/`module_eval` and `instance_eval` of a String, and
`class_eval`/`module_eval` with a block, that boot ran on a named
module are compiled into that module as its body (a block run on
several modules is each one's body); the call site is a no-op. An
eval on anything else is a compile error. Boot also records
Forwardable's `def_delegators` lists by call site, for a list built
at load time.

*See also decision 374:* a run-time `instance_eval(string)` the trace saw (a tap's cask) compiles at its call site.

*See also decision 427* (prism): a boot-recorded class_eval site is registered before any file is collected, so a gem the traced entry loads first (racc) finds it.

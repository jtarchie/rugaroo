# Decision 459

**Rule:** $_ is per frame and per thread: a spec DSL block (`describe`, `it`, `before`, ...) and a `Thread.new`/`start`/`fork` block each have their own, `recv.send(:gets)` (and `readline`, `public_send`, `__send__`) sets it, and `io.print` with no argument prints it; a class statement hoisted from a block (decision 451) is declared past any `describe` class, and refused when it inherits from an instance's `self`.

**ruby/spec regressions from decisions 446 and 451** (amends 446, 451; 2026-11-13). *See also decisions 446, 451, 458.* The ruby/spec refresh after the batch of decisions 445-457 was compared test by test against a rerun of the last published commit (2887634c), and these came out.

- **`$_` in spec blocks.** cmd/rubyspec's `it` and `before` blocks become methods of the describe's class (spec.go), after decision 446 had lowered `$_` with the enclosing frame's local: the new method has no such local, so `library/stringio`'s "sets $_ to the read content" became a compile error ("undefined local $_"). A spec DSL block is now its own frame, which is what the method minitest defines from it is.
- **A sent `gets`.** Those specs read the line with `@io.send(@method)`. In a frame that keeps `$_`, `recv.send(m, ...)` (also `public_send`, `__send__`) is lowered to `$_ = __line_or(m, recv.send(m, ...), $_)` when `m` reads without side effects (a Symbol or String literal, a local, an ivar), so it is evaluated twice safely: `$_` takes the result only when `m` names `gets` or `readline`, as MRI.
- **`io.print` with no argument** prints `$_` in MRI (IO#print and StringIO#print). Decision 446 lowered only a bare `print`. A receiver's `print` with no argument now gets `$_` when it resolves to the prelude's; a program's own `print` method is called as written. `library/stringio` "prints $_ when passed no arguments" passes again.
- **A thread's `$_`.** MRI's `$_` is thread-local as well as frame-local; decision 446 let a `Thread.new` block share its method's. `language/predefined` "is Thread-local" now passes.
- **A class reopened in a describe.** Decision 451 declared a class statement from a block in the scan's lexical scope; inside a describe that is the describe's hidden class, so `class BigDecimal` in a `before` made `RbSpec32::BigDecimal`. A describe is a block in MRI and does not nest constants: the hoist skips describe classes.
- **`class X < self`** in a block where `self` is an instance (a method body, or the top level's `main`) raises TypeError in MRI. Decision 451 hoisted it as a subclass of the enclosing class; it is now a compile error. In a class body's block `self` is the class and it is hoisted as before.
- **Proof:** `testdata/run/io_last_line.rb` (a sent `gets`, `StringIO#print` with no argument beside a program's own `print`, a thread's `$_`); `testdata/test/spec_test.rb` ("last line", "class in before"); `testdata/errors/objects.txtar` `class_in_block_self_super`; `library/stringio`, `library/bigdecimal`, `language/predefined`, `language/class_spec`.

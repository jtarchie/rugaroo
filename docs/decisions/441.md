# Decision 441

**Rule:** A leaf `Data.define` class with typed members that fit Go's SSA cap (at most 4 fields, at most 32 bytes, no Proc) is a Go value struct `C`, not `*C`, unless user or gem code anywhere observes identity (`equal?`, `object_id`, `__id__`, `compare_by_identity`, `assert_same`, `instance_variable_set`, `ObjectSpace`, `WeakRef`, `Marshal`); a plain leaf class marked `# @value` is one by assertion, and a `# @value` class that cannot be one, or a typed `equal?`/`object_id`/`freeze`/`instance_variable_set` on it, is a compile error; a value class's `C?` is `rbOpt[C]`.

**Small immutable classes by value** (#119; amends 359, 360, 396; 2026-11-11). *See also decisions 30, 89, 359, 360, 378, 396.* A leaf class is `*C` (decision 359), so every `new` that outlives its expression is a heap allocation: Go's escape analysis keeps an inlined temporary on the stack, but a loop-carried value (`acc += d`), one stored in an ivar or an Array, or one returned from a non-inlined method escapes. Measured in the research (instructions retired, GOMAXPROCS=1): a 2-Float `acc += d` loop was 1,713M as `*Vec` and 141M with a five-line hand edit to a value struct, 12x.

- **Which classes.** Spinel does this after typing (`detect_value_types`, `is_value_type`), with a long list of disqualifiers that exist for its C GC rooting; a Go value is copied freely, so only immutability and identity matter here, and both are known before any body is emitted:
  - **A, Data.** MRI's own contract makes a Data object a value: frozen, no setters, `==`/`eql?`/`hash` by member, `inspect` without an address. So a Data class is a value whenever it is a leaf, every member is typed, the fields fit the cap, its block defines no `initialize` (nor `initialize_copy`/`_dup`/`_clone`: a value's `dup` is the value) and writes no instance variable, the program asks no ivar question that sets `ivarBits` (decision 153), and a name-level scan of every user and gem file (not the prelude, not the generated member source) finds no identity observer. The scan is coarse on purpose: a hit anywhere keeps every Data class a pointer, silently, exactly as before. Beyond the identity methods themselves, `assert_same`/`refute_same`/`must_be_same_as`/`wont_be_same_as` are in it because minitest's `equal?` is prelude code the scan skips; `instance_variable_set`/`remove_instance_variable` because MRI raises FrozenError on a Data object and a copy would take the write silently; `Marshal` because `rbMLoadObj` fills a `*C` (ponytail: load a value class by value).
  - **B, `# @value`.** A plain class has no such contract, and only a whole-program typed pass sees the identity sites (`a.equal?(b)` in another body, `xs.include?(v)` and `h[v]` in generic prelude code through `rbEq`/`rbIdentical`), which would mean a second compile for every program with a small class. So a plain class is a value only when the program says so: a `# @value` comment line right above `class C`, spelled like the class-level `# @go_type`/`# @hidden` directives (a `key: mode` line such as `# int_overflow:` is file-wide, and an unknown `# @rbs value` would be rbs-inline's to reject). Nothing may follow `@value` on the line (a misspelt assertion would keep the pointer silently). The same eligibility as A must hold, each failure a compile error at the class naming the reason (a writer, `bump writes an instance variable (line N)`, `its initialize uses self as a value`, more than 4 ivars, more than 32 bytes, a Proc field, a subclass/superclass/user module), plus a typed `equal?`, `object_id`, `__id__`, `freeze`, `instance_variable_set` or `remove_instance_variable` on it (`self` inside its methods included). A `# @value` above `P = Data.define(...)` turns A's silent fallback into these errors and skips the scan. `class P < Data.define(...)` stays a pointer either way: the hidden Data root has a subclass.
  - **Rejected: type-based detection for plain classes.** It needs the typed identity sites, so a restart through the `needInstances` path whenever a candidate meets one; most programs with a small class would compile twice (any `assert_equal` on objects, any Hash keyed by them), against `TestCompileCost`, and its correctness would rest on a hand-kept list of prelude methods that compare elements.
  - **Rejected here: mutable small classes** (spinel's `bm_nbody` Planet, `bm_ao_render`'s `v.x = v.x / len`). Value semantics with in-place writes needs an ownership analysis; spinel has none either. Its own issue if wanted.
- **Size cap: exactly Go's `ssa.CanSSA`**, `NumFields <= 4` and `Size <= 4*PtrSize` (`cmd/compile/internal/ssa/value.go`). Past it a struct lives in memory, and the research's micro-benchmark had a 5-field value struct 6x slower than a stack-allocated pointer temporary (11.85 vs 1.95 ns). Field sizes: Integer and Float 8, Boolean 1, String and Symbol 16, `Integer?`/`Float?` (`rbOpt`) 16, any pointer 8, an interface 16; anything else (untyped, a Proc, a tuple, a field naming another Data or `# @value` class, whose own Go type is being decided) is refused. A rugaroo String is a Go `string`, so a value class holds at most two.
- **Representation.** `Class.byValue` is set by `markValueClasses`, after `refineIvars`/`markIvarBits` (ivar types final) and before `inferReturns` and emit, so a class's Go type is decided once.
  - `objType`/`recvType` are `C`; the struct holds only its fields (a Data class drops the `super_Data_` embed and every program-wide extra: the frozen flag, the WeakRef pointer, which would be a fifth field). Every Go method takes a value receiver (`recvcheck`): `_C()` returns `&self`, a copy, and the dropped embed's `_Data()` marker is a stub.
  - `NewC` returns `C`: `var self C; C_Initialize(&self, ...); return self`. `initialize` alone takes `*C` (`valueInit`), its `self` is `(*self)`, and `ivarPath` writes the field itself (`(*self).x = v`) rather than through `_C()`, whose copy would drop the write. Every other method takes `self C`.
  - `C?` is `rbOpt[C]`: `valScalar` holds for a value class and `nilObj` does not, so every decision 396 site (narrowing, `&.`, `||`, `compact`, `boxedValOpt`'s `rbOptFromPtr`/`rbOptToPtr`) applies unchanged, and `rbUnbox`/`rbKeyUnbox` get one `case rbOpt[C]` each.
  - Boxing to untyped is `any(x)` (no `rbPtrAny`: a value is never nil); dispatcher arms are `case C:`; `rbClassRefs` is false, so `object_id` hashes the value and Kernel's `inspect` shows no address. `_Dup` returns the value, `_Copy` copies the fields, `_IvarSet`/`_IvarDel` are not emitted (frozen), Marshal has no case.
- **Semantics a `# @value` class takes on**, documented in docs/support.md: the default `==`, `eql?` and `hash` compare the fields (Go `==` on the value, as `rbIdentical`/`rbEq` already do for a non-reference), where MRI compares identity; Kernel's `inspect`/`to_s` print `#<C @x=1>` without MRI's `0x...` address. A class that needs MRI's identity equality is not a value class. Data's own `==`/`eql?`/`hash`/`inspect` are generated and unchanged.
- **Measured** (instructions retired, GOMAXPROCS=1, binaries alternating, min of runs, against 979fbe09): `benchmarks/objects.rb` with its `Vec` marked `# @value` 432M to 364M (-15.7%, 7 pairs); the research's Data loop (`acc += d` on `Data.define(:x, :y)`, 10M iterations) 1,802M to 128M (14x, 5 pairs). `TestCompileCost`: unchanged (none of its programs has a Data or `# @value` class).
- **Gen-compare** (`gen` with 979fbe09 and this, over examples/*/main.rb, testdata/run/*.rb, benchmarks/*.rb): 206 byte-identical; 5 differ, each with a Data or `# @value` class (examples 028, 093, 137, testdata/run/string_output.rb, benchmarks/objects.rb); 4 not compared, the `# trace:` programs (examples 123, 124, benchmarks/kramdown.rb, liquid.rb), which `gen` alone cannot load.
- **Proof:** `testdata/test/value_test.rb` (a Data class in Arrays, Hash keys, `tally`, `Set`, `==`/`eql?`/`hash`, `with`, patterns, `inspect`, `C?` in an ivar and `Array[C?]`, untyped, `frozen?`; a `# @value` class through arithmetic, Comparable, an owner's attr_accessor and `Vec?`), against MRI; `object_test.rb`'s `here.with.equal?(here)` keeps Data a pointer and answers MRI's identity; `testdata/errors/value.txtar` (each B refusal); `TestValueClasses` in internal/compiler pins which programs get `C` and which keep `*C`; example 137.

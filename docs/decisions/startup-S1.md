# Decision S1

**Rule:** `--regexp-compile=lazy|eager` (or a file's `# regexp_compile: mode` line, for the literals written in that file) picks when a Regexp literal compiles its pattern: `lazy`, the default, at the literal's first use, once, behind that Regexp's own `sync.Once`; `eager` when the program starts, as before; a gem's interpolated regexp follows the same switch; results are the same in both.

**When a Regexp literal compiles** (amends decisions 24 and 176; 2026-11-16). *See also decisions 242, 332, 372.*

A static literal was `var rbRe_<hash> = rbRegexpNew(...)`, and Go initializes every package variable before `main`: a program compiled every pattern it contains before its first line ran, including the patterns of code it never reaches and of files MRI never loads. Compiled rubocop holds 463 of them, six of which are unicode-emoji's generated patterns (37 to 75 KB of source each, compiled by regexp2); MRI autoloads those files and never does. They were 340M of the 2,193M instructions rubocop spends on an empty file, and Regexp construction was 77% of kramdown's start-up, 46% of cuba's and 38% of liquid's (`docs/research/startup-2026-11.md`).

- **Lazy (the default).** The variable is `rbRegexpLazy(pattern, src, opts)`: a Regexp that holds its translated pattern and compiles it at its first use. A gem's interpolated regexp (decision 176's `rbRegexpLenient`) is `rbRegexpLenientLazy`: built where the gem builds it, translated and compiled at its first match.
- **Eager.** Today's code exactly: `rbRegexpNew` in the variable's initializer, `rbRegexpLenient` where the gem builds the regexp. For a program that must fail fast, or that wants no compile inside its first match.
- **The mechanism.** `Regexp`'s compiled pattern is an `atomic.Pointer`, read through one accessor, `rx()`: a load and a nil test, inlined, in both modes. A lazy Regexp's pointer is nil until `rxFirst` compiles it under the Regexp's own `sync.Once` (in `rbRxLazy`, behind a pointer). No lock is shared between Regexps and there is no table. StringScanner's `\A`-anchored twin lives in the compiled pattern's slot, reached through `anchSlot()`.
- **What does not change, in either mode.** A malformed static literal is a compile error: the compiler still translates and compiles every literal. A user-code interpolated Regexp (`rbRegexpDyn`), `Regexp.new` and `Regexp.union` compile, and raise `RegexpError`, where they are built. `source`, `inspect`, `to_s`, `==`, `hash`, `options`, `frozen?` and Marshal read the source and options and compile nothing.
- **The one difference, and why it cannot be seen.** In lazy mode a pattern the Go engines reject at run time would raise at its first use instead of at start. For a static literal that cannot happen: the compiler compiled the same translated pattern with the same engines, and a failure there is the compile error. For a gem's regexp, decision 176 already made the error wait for the first use; lazy mode moves the work, not the error. A lazy Regexp whose compile does fail becomes one that raises `RegexpError` at each use, as `rbRegexpLenient`'s does.
- **Plumbing** is decision 372's: the CLI flag sets `RUGAROO_REGEXP_COMPILE`, `envConfig` carries it (so the inference cache keys on it), and a file's own line wins for its literals. The mode is part of a literal's variable (`regexpVars` keys on the constructor), so one pattern written in files of both modes gets two variables.
- **Measured** (instructions retired, macOS arm64, `GOMAXPROCS=1`; eager → lazy): kramdown load and convert `"x"` 216.0M → 148.2M (−31%), cuba load 65.4M → 58.9M (−10%), liquid load and one render 52.2M → 47.6M (−9%), hello-world 17.9M both. The accessor costs `benchmarks/regexp.rb` 0.2% with the collector off (2,463M before, 2,467M eager, 2,469M lazy; minimum of five runs).
- **Proof:** `TestRegexpCompileMode` (the generated Go per mode, the file line, a bad mode, an eager program run); `testdata/test/regexp_extended_test.rb`'s `RegexpCompileTimeTest` (first use from several threads, by a scanner, of a lookbehind; source and identity without a match), equal to MRI in both modes; the eager lane is `RUGAROO_REGEXP_COMPILE=eager go test ./...`.

# Decision 455

**Rule:** `s.replace(t)` and `s.clear` on a String local that decision 382's proof allows appends to, or on an out parameter, rebind it to `t` or `""`; a prelude instance method no program class overrides may take out parameters (decision 405); `Encoding::Converter#primitive_convert` is built on both.

**String rebinding and prelude out parameters** (#156, #151's follow-up; amends decisions 382, 405 and 452; 2026-11-13).

`primitive_convert(src, dst)` appends its output to the caller's `dst` and empties the caller's `src`. Decision 405 let a class method or a gem instance method append to a caller's String, not a prelude method, and only by appending; `replace`/`clear` on any program String were "Strings are immutable".

- **Rebinding** (`strRebindNames`, `userRebind`). In decision 382's proof, `s.replace(t)` and `s.clear` count where an append does (their value is `s` itself); codegen is the gem path's `stringReplaceBang` (decision 416), assigning the local. It is safe even when `t` is another String: they share bytes, and the next append to either goes through `rbStrAppend`'s buffer check, which copies when the local's buffer no longer holds its String. On an out parameter the rebinding reaches the caller through the deferred write-back, as an append does.
- **Prelude out parameters** (`markOutParams`). A prelude instance method qualifies as a gem's does (amends decision 405's gem amendment): not a module's, no program descendant redefines it, and a public one overrides no ancestor's. Prelude methods with `%x{}` bodies never append to a Ruby parameter, so none changed shape.
- **`primitive_convert(src, dst, off, size, opts)`**: `src` converted onto the end of `dst` and `src` emptied; `:finished`, or `:source_buffer_empty` under `PARTIAL_INPUT` with a cut UTF-8 character held for the next call; on an error, the characters before the bad one are appended (as MRI's converter has written them) and `:invalid_byte_sequence` / `:undefined_conversion` returned. Not built: `off`/`size` (MRI's buffer room), `putback`'s bytes, src keeping the bytes after an error.
- **Caller's side:** as decision 405, the arguments must be String locals the caller owns.
- **Proof:** `testdata/test/encoding_test.rb` `ConverterPrimitiveTest`, `testdata/test/string_test.rb` `StringRebindTest` (a local's replace and clear, a String shared by replace then appended, replace through an out parameter) against MRI.

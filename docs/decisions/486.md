# Decision 486

**Rule:** A private def dispatches by type switch as a public one does (decision 212); attr accessors stay Go methods on their owner.

**Private defs leave the Go method set** (2026-11-21; amends 212; docs/research/function-count-2026-11.md option B). *See also decisions 208, 210, 212, 213, 234, 253, 485.*

`plainMethod` admitted only public defs, and decision 212 did not say why. A private method nothing overrides is already its free func, called directly (`staticPrivate`, decision 253), with no interface slot and no forwarder. One a subclass overrides is an interface slot with a forwarder on every class below its owner: rubocop's `Cop::Base#range_for_original` and `#apply_correction` were 614 forwarders each. Now such a method dispatches like a public one: a self call is the owner's free func, or its `rbSend_` switch when overridden, and the name leaves the interfaces. `RUGAROO_NO_PRIVATE_DISPATCH=1` keeps the old rule.

- **No real reason for public-only.** Visibility is checked where a call is resolved, before dispatch is chosen (`checkVisibility`: a private method with an explicit receiver is a compile error in typed code); `send`, `public_send`, `respond_to?(x, true)` and an untyped receiver's call go through the Dyn wrappers and the `rbHas_Private` tables, which read the class's own resolution and never the Go method. Nothing in prelude Go selects a private name. With the admission open, `go test ./...` finds no failure.
- **A private method nothing overrides keeps its direct call** (`dispatchCall` skips `staticPrivate`): a module's one would otherwise switch from `Mod_X[Self](self)` to an instantiation at the constraint, `Mod_X[Mod_Self[any]](self)`, which is a new instantiation where the caller's Self is a class interface (`116_cuba_web`'s `Rack::Request::Helpers`, +11 compiled functions).
- **Attr readers and writers are not admitted.** They are not free funcs: `emitMethod` writes them as Go methods on the owner's struct, which subclasses get by embedding, so they have no forwarders to remove (`needsForwarder`), and a dispatched one would still be a Go method on every class (Go's promoted wrapper). Removing those means emitting accessors as free funcs, a separate change. rubocop's `Cop::Base#config` and `#processed_source` are defs in the compiled gem, kept as Go methods by the modules that call them on self (below).

**Measured** (rubocop 1.92.1 `main.go`): functions 176,135 → 174,870, forwarders (census) 51,092 → 49,811, main.go 103.05 → 102.82 MB. Still forwarded: the private names whose override has another Go signature (`Cop::Cop#callback_argument`, `Lint::Syntax#find_severity`). `TestCompileCost` unchanged (005 2,086, 064 8,274, 116 33,439 compiled functions).

**Proof:** `testdata/test/dynamic_test.rb` (`DispatchPrivateTest`: a private override run from the base's body and from a module's, `send` and `public_send` on it, `respond_to?` with and without `true`).

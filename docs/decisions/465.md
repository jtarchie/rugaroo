# Decision 465

**Rule:** `String#unpack` of a literal format made only of starred fixed-width integer directives or `U` (`"U*"`, `"C*"`, `"n*"`; not `"C2n*"`, `"L_*"` or `"Q*"`) is an `Array[Integer]`; `rbMust`/`rbMustO` raise from an out-of-line helper so they inline.

**Typed unpack** (amends decisions 324, 352; 2026-11-15). *See also decision 439.*

`unpack` returns `Array[untyped]`: a format may yield Strings, Floats, Integers and nil. A scanner that reads its input as code points (`@source_pts = source.unpack('U*')`, the parser gem's lexer and every Ragel-generated one) then holds an untyped Array, and every comparison against an element is a dynamic call.

- **The twin.** `stringLiteralOverload` (and `gemCallShortcut`, before a gem's wrapping twin) picks `__unpack_ints` when the format literal matches `unpackIntsRe`: one or more of `C c S s L l N n V v U`, each with an optional `<` or `>` and a `*` count. A starred directive never yields nil for a short String, and each of these is at most 32 bits (U: a code point), so every element is an Integer in every `--int-overflow` mode. A counted directive (`C4`) can yield nil and stays untyped, as do the native-size `_`/`!` forms (`L_` is an unsigned 64-bit long) and `Q`, `J`, `w`, whose values can pass 2**63.
- **`rbUnpackInts`** decodes `"U*"` and `"C*"` directly into a `[]Integer` (no boxed element, no second pass); other formats convert `rbUnpackWrap`'s values.
- **`rbMustFail`.** `rbMustO(opt, "Integer")`, a gem's `Integer?` where an Integer is wanted (decisions 172, 396), built its TypeError inline, which put it over Go's inlining budget: it was a generic call per use, 15% of a typed scanner loop. The raise moved to a `//go:noinline` helper.
- **Measured** (instructions retired, `GOMAXPROCS=1`): a Ragel-shaped scanner in gem code (class-level Integer tables read through `send`, `unpack("U*")`, a `case` per character; 2.9M characters) 3,383M → 349M; MRI 4,653M, so 1.4x → 13.3x MRI.
- **Proof:** `testdata/test/string_test.rb` `StringUnpackIntsTest`; `testdata/run/gem_lenient/ragelish.rb`.

# Decision 485

**Rule:** A module method's Dyn wrapper is one shared arm for every includer whether or not the method is dispatched (private ones too), the public and private arms of a name are one class-ID switch, and `rbRespondsX` holds its class table inline.

**Fewer functions for a large program** (2026-11-21; amends 209, 234; applies 208 to Dyn wrappers). *See also decisions 85, 208, 209, 212, 234; docs/research/function-count-2026-11.md.*

A census of compiled rubocop's `main.go` (217,329 functions, 113.7 MB): 63,970 were Dyn wrappers, and 33,041 of those called a module's free func instantiated at the class's own interface,

```go
func (self *RuboCop_Cop_Style_AndOr) _DynLine(args ...any) any {
	return RuboCop_Cop_Util_Line[RuboCop_Cop_Style_AndOrI](self, args[0])
}
```

486 module methods, each on about 615 cops and 633 `PathUtil` includers. Each cost a function, and each type argument is its own GC shape, so Go compiled the module's body again per class. The forwarders had stopped doing this in decision 208 (`Mod_Self[any]`), and decision 234 gave a *dispatched* module method one shared arm; `dispatchable` excludes private methods, so every private module method missed it.

- **Module arms.** `dynShareable` takes decision 208's condition as well as 234's: no type parameters on the module, a signature that does not mention the class, a constraint that does not name `Self` (`Comparable` keeps its wrappers). The body is rewritten to `Mod_X[Mod_Self[any]](self, ...)` and shared; `self` is the receiver itself, asserted to the constraint, so calls through it reach the subclass's own methods and the module's ivars are the same object's.
- **One switch.** `emitDynArms` emitted the public arms' switch and then the private arms', the second behind `how != rbCall`. With many private arms a public receiver of the same name paid a second assertion and a missed search. A class resolves a name one way, so the IDs are disjoint: one switch, public cases first, a private case opening with `if how != rbCall`.
- **Respond tables.** `rbHas_RespondsX`, a class-ID switch, had one caller, `rbRespondsX`: the switch is in it now (`markerChecks`). `rbHas_PrivateX` has three readers and stays.

**Measured** (rubocop 1.92.1, default lane, idle 32 GB machine):

| main.go | 113.7 MB | 103.1 MB |

Compiled rubocop's output equals MRI's on five inputs (a syntax-error file, two single files, `prelude/array.rb`, a directory of nine), and its instructions retired are within 2% of before on each (5,935M -> 5,899M on the directory).

**Proof:** `testdata/test/dynamic_test.rb`, `object_test.rb`, `module_test.rb`; `TestCompileCost`; `overrides/rubocop/check`.

# Decision 446

**Rule:** `$_` (English's `$LAST_READ_LINE`) is a hidden local of each frame (the program, a def, a class body) that reads or writes it, directly or through a bare `print` or `~ /re/`; every `gets`/`readline` call written in that frame assigns it, its blocks share it, and a frame that never uses `$_` compiles as before.

**`$_`, decided at compile time** (#147; amends decisions 415 and 425; 2026-11-13). *See also decisions 61, 361, 362.* *See also decision 459 (spec, thread and sent-gets frames).*

MRI keeps `$_` per method frame (and per thread), not as one global: a method that calls `gets` changes only its own. So it is a local the compiler can place, unlike `$.` (decision 425), which is a real process-wide value.

- **Rewrite** (`lowerLastLine`, `internal/compiler/lastline.go`, an AST pass beside decision 362's `lowerMainIvars`). For a frame whose own code (not nested defs or classes) names `$_`/`$LAST_READ_LINE`, has a bare `print` or `~ /re/`: reads and writes become a local named `$_` (Go `lastLine_`; the `$` keeps every Ruby local name off it), each `gets`/`readline` call with no block, on any receiver (Kernel, ARGF, an IO, StringIO; all set `$_` in MRI) becomes `$_ = <call>`, a bare `print` prints `$_`, and `~ /re/` becomes `$_ ? /re/ =~ $_ : nil`. The frame starts with `$_ = __no_line` (a Kernel helper typed `String?` that returns nil), so a frame whose first `gets` is in a block still has one local, and a frame that only reads `$_` reads a `String?` nil.
- **Cost:** none for a program that does not use `$_`; one store per `gets` in a frame that does.
- **Not built:** the `-n`/`-p` command-line modes and the `Kernel#chomp`/`chop`/`sub`/`gsub` forms that only exist under them; a bare regexp literal as a condition (`if /re/`, Prism's `MatchLastLineNode`, which MRI warns about); a user class's own `gets` in a frame that uses `$_` is assigned to `$_` too, which is MRI's behaviour only for IO-like readers.
- **Proof:** `testdata/run/io_last_line.rb` (`# stdin:`): a method's own `$_` against the top level's, blocks sharing their method's, `while gets` with bare `print` and `~ /re/`, `$_ =`, `$LAST_READ_LINE`, a method that never reads a line.

*Amended (2026-11-13, same day):* a bare `print` gets `$_` only where the call resolves to Kernel#print (`lastLinePrint`, at call generation); the parse-time pass marks such calls on the file (`File.lastLinePrints`). Before, a program's own `def print` (a class's, or a top-level one) called bare was passed `$_` and failed to compile ("wrong number of arguments"); `testdata/run/io_print_override.rb`.

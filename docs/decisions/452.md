# Decision 452

**Rule:** `Encoding::Converter` is a prelude class over String#encode's transcoder (decision 380): `new` with encode's options and `newline:`, `convert` (a UTF-8 character cut at the input's end waits for the next call), `finish`, `last_error`, `primitive_errinfo`, `replacement`/`replacement=`, `insert_output`, `convpath`, `==`, `inspect`, `.search_convpath`, `.asciicompat_encoding` and the flag constants; `primitive_convert` and `putback`'s bytes are not built.

**Encoding::Converter** (#151; 2026-11-13). *See also decisions 136, 380, 382, 405.*

- **On encode.** Each `convert` transcodes what it is given with `String#encode(dst, src, **options)`, so the tables, messages and error objects (`error_char`, `error_bytes`, `readagain_bytes`, `source_encoding_name`, ...) are encode's. An error is kept as `last_error` and in `primitive_errinfo` (`[:invalid_byte_sequence | :undefined_conversion, src, dst, bytes, readagain]`) and raised.
- **Streaming.** A UTF-8 source's trailing bytes that begin a character the input does not finish are held for the next `convert` or for `finish`, which converts (or raises on) what is left, as MRI's converter buffers them. Other sources convert each call whole.
- **`undef` keyword.** Ruby code cannot read a parameter named `undef`, so `initialize` is a `%x{}` that hands the keywords to `__setup`.
- **Not built (design limits).** `primitive_convert(src, dst, ...)` fills the caller's `dst` and consumes the caller's `src` in place. Strings are immutable values in rugaroo, and an instance method cannot take a String parameter by reference (decisions 382 and 405 cover appends to a local or to a class method's or top-level def's parameter). `putback` returns `""`. Strings carry no encoding tag (decision 136), so a converted String's `inspect`/`encoding` reflect its bytes, not the destination encoding.

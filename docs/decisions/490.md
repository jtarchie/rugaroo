# Decision 490

**Rule:** `Mutex#synchronize` takes the lock, runs the block and unlocks in a deferred call with the goroutine id it locked with: one id lookup and no ensure frame, the same checks as `#lock` and `#unlock`; a contended Mutex is Go's `sync.Mutex`, whose sleep-and-wake handoff is the floor.

**The mutex row** (2026-11-22). *See also decisions 104, 332, 488.*

`benchmarks/mutex.rb` (eight threads, 300,000 `synchronize { counter += 1 }` each) is the one row where rugaroo trails MRI and spinel: 0.34 s against MRI's 0.33 s and spinel's 0.17 s.

- **Where the time goes.** A CPU profile of the compiled program is 78% `pthread_cond_wait` and `usleep`, and most of the rest Go's `lockSlow`/`unlockSlow`: the runtime parking and waking OS threads as the lock passes between goroutines on different cores. rugaroo's own code is about 1% (`rbGoID`).
- **Plain Go is the floor.** The same program written by hand in Go with a `sync.Mutex` takes 0.14-0.32 s (best of nine 0.17 s; the spread is the scheduler). With `GOMAXPROCS=1` it takes 0.01 s and rugaroo 0.03 s: the cost is real parallel contention, which MRI never meets (its threads take turns under the GVL) and which spinel's green-thread workers park in user space.
- **What changed.** `synchronize` was `lock`, a Ruby `begin`/`ensure` (an `rbBegin` closure) and `unlock`, looking the goroutine id up twice. It is now a Go body: one `rbGoID`, `Lock`, a `defer` of `rbMutexSyncUnlock` with that id, and the block. Uncontended it retires 528M -> 350M instructions on the benchmark (`GOMAXPROCS=1`); contended the wall time does not move, as the profile says. Recursive locking, a block that unlocks the mutex itself, a `break` and a `raise` out of the block behave as before and as MRI's.
- **Not done:** a lock of rugaroo's own (spinning, or parking in user space) to beat `sync.Mutex` here. The runtime uses Go's primitives only, and the row is a lock-handoff microbenchmark: a program whose threads do work between locks runs in parallel, which MRI cannot.

**Proof:** `testdata/test/control_test.rb` `ControlMutexSyncTest`.

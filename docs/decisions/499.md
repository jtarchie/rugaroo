# Decision 499

**Rule:** Inference rounds use the not-known-yet type, in three phases each run to a fixed point, by default; `RUGAROO_INFER_UNKNOWN=0` selects the older rounds until they are removed.

**The not-known-yet rounds are the default** (2026-11-26; ends the opt-in of docs/research/inference-2026-11.md). *See also decisions 146, 444, 474-477, 484, 487, 491, 492.*

`RUGAROO_INFER_UNKNOWN=1` chose a second way of running the rounds: a value nothing has typed yet is "not known yet" instead of untyped, each slot's type only goes up, and the rounds run in three phases (types only, settling, resolved). Decision 487 said it "ends by becoming the default and the old path going". This is the first half. The owner chose to flip before cutting the cost of the extra rounds.

- **What changes for a program.** `scripts/gen-compare` of the two lanes over 347 inputs (examples, testdata, benchmarks, spinel's benchmarks): 335 generate the same Go, 12 differ, none newly fails and none newly compiles. The 12 are the programs that compile gem code (`123_kramdown`, `124_liquid`, `116_cuba_web`, `120_pairing_heap`, `135_roundhouse_blog`, the kramdown and liquid benchmarks, `gem_inference`, `gem_lenient`, `prism_test`) and two spinel programs that fail in both lanes with another message (`bm_micro_lisp`, `bm_tree_walker_frames`). No program of strict user code generates different Go.
- **Run time** (instructions retired, median of 9 runs, output equal to MRI in every build):

| | older rounds | not-known-yet |
|---|---:|---:|
| `benchmarks/kramdown.rb` | 3,793M | 3,745M (-1.3%) |
| `benchmarks/liquid.rb` | 1,671M | 1,657M (-0.9%, inside the runs' spread) |

- **Dynamic-call warnings:** liquid 477 and 476, kramdown 973 and 957, cuba 100 and 100. The lane alone types little more; it is what decision 500's rule needs, since a type can now arrive in a later round without an earlier untyped value having settled the slot.
- **Cost.** More rounds: liquid 6 -> 15, kramdown 8 -> 10, cuba 4 -> 6. Transpile, warm, inference cache off: liquid 4.9 -> 7.7 s, kramdown 15.7 -> 19.7 s, cuba 5.5 -> 5.7 s. A program whose inputs did not change still starts from the cache and runs no rounds (decision 430). rubocop was not re-measured for this decision; on 2026-11-21 its transpile was 3.9x under the switch. Cutting the rounds' cost is the next piece of work.
- **Two rules of the older rounds a state that only goes up had lost**, both in user code, both found by the suite:
  - *A union that breaks its own method is given up* (decision 150). `def wrap(x) = takes_int(x)` called with 1 and "a": the first round types `x` `Integer | String`, the body does not compile, and the older rounds then typed `x` from the first call and reported the second call. Joined back with the earlier round's union, the error was the body's, at another line. A parameter marked `noUnion` now keeps the round's type.
  - *A type every use has stopped supporting is dropped after resolution.* A parameter typed in an early round from `c.get`, when `@value` was `Integer | String | nil`, kept that type after a computed `send` made `@value` untyped, and the call checked the value at run time against a type MRI does not hold it to. Once the rounds are resolved, a program's parameter whose every use is untyped is not kept from an earlier round: it is untyped, with decision 183's warning, as before.

  With both, the two cases generate the Go the older rounds do (`testdata/errors/infer.txtar` `union_breaks_body`, `TestUncalledWriterIvarTyped`).
- **The switch.** `RUGAROO_INFER_UNKNOWN=0` is the older rounds, for an A/B while the cost work is done. The inference cache's key holds the environment, so the two lanes never share an entry.
- **Proof:** the suite in the new default; `TestUntypedReport` runs both lanes (`0` and `1`).

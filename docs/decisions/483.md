# Decision 483

**Rule:** A long, valid, non-ASCII String's cached facts (decision 464) include the byte offset of every 64th character, so `s[start, count]` and a character offset far into it walk at most one stride instead of the String from its start.

**Found by profiling compiled rubocop** (2026-11-21; amends 464). *See also decisions 349, 399, 449, 464.*

`rugaroo build -profile-out` (decision 449) on rubocop over nine of the prelude's larger files: 56% of the samples were `rbRuneOffset`, under `Parser::Source::Buffer#slice`. The lexer takes every token's text with `slice(start, length)`, a character position into the whole source. For an ASCII source that is a byte slice (decision 399). For a source with one non-ASCII character it was a walk from the first byte to `start`, per token: quadratic in the file. The parser gem avoids exactly this on MRI by keeping a UTF-32LE copy of a non-ASCII source (`@slice_source`), which MRI indexes in constant time; rugaroo's Strings are UTF-8 whatever their encoding says, so the copy bought nothing.

`rbStrFact` gains a level, `rbFactIndex`: `idx`, the byte offset of every `rbIdxStride`-th (64th) character, built in one pass that also counts the characters. `rbRuneOffsetLong` reads it for a String of 1 KB or more and a position 128 or more characters in, then walks the remainder with `rbRuneOffset`; anything shorter, nearer, ASCII, or after `rbStrSetbyte` has made Strings mutable (`rbStrMutable`) walks as before. `rbStrSub` and `rbCharOffset` use it. The cache is decision 464's: direct-mapped by length, whole entries swapped atomically, no lock.

**Measured** (rubocop 1.92.1, default lane, nine prelude files, instructions retired): 17,765M -> 6,282M; MRI 12,050M. The same binary reported the same offenses before and after.

**Not this decision's, seen in the same run:** on `prelude/file.rb` compiled rubocop reports 49 `Lint/Syntax` offenses that MRI's run does not (the Ruby 2.7 grammar meeting an endless `def`); it did before this change too. Open.

**Proof:** `testdata/test/string_test.rb` `test_slice_long_non_ascii` (positions at the stride's edges, the ends and past them, lengths that are and are not a multiple of the stride).

# Decision 474

**Rule:** Ivar discovery walks class objects before instances, so an instance ivar written from a class-level accessor (`@cs = self.class.lex_en_start`) takes that accessor's type; and `String#scan` with a block is the block form whatever the pattern's groups.

**Class objects first in ivar discovery; `scan` with a block** (2026-11-21). *See also decisions 322, 334, 445.*

Two default-lane fixes found while typing the parser gem's lexer without its vendored signature (`docs/research/inference-2026-11.md`).

- **Class objects first.** `discoverIvars` dry-runs each class's methods in `classList` order, and a class comes before its metaclass. Ragel's generated code keeps its state numbers in class-level accessors (`class << self; attr_accessor :lex_en_expr_value; end; self.lex_en_expr_value = 229`) and reads them from instance methods (`@cs = self.class.lex_en_expr_value`). The instance method was walked while the class object's ivar had no type yet, so the read was untyped, `@cs` was declared untyped by that first write, and the second walk could not narrow it (untyped joined with Integer is untyped). The walk now takes metaclasses first (a stable sort, nothing else reordered). `@cs` is then `Integer?`: a class-level accessor may be unset, as before.
- **What it does not do.** A class method that reads an instance's ivar through a reader still sees it one walk late; the two walks cover that, as they did.
- **`scan` with a block.** `stringLiteralOverload` picked the blockless `__scan_groups` for a literal pattern with groups even when the call had a block, and the call failed with "`__scan_groups` does not take a block". With a block the overload is left to `blockOverload`, which picks `__scan_block`: it yields each match's groups, or each match, as MRI decides from the pattern.
- **Measured:** `scripts/gen-compare` of main against this change over examples, testdata, benchmarks and spinel's suite (345 inputs): the only inputs whose Go differs are `testdata/run/gem_inference.rb`, which gained the fixture below, and `testdata/test/string_test.rb`, which gained the `scan` test and did not compile before.
- **Proof:** `testdata/run/gem_inference/lib/lexen_gem.rb` (the accessor read by the class itself and by a second class that holds it); `string_test.rb` `test_scan_groups_block`.

# Decision 462

**Rule:** rack's and rackup's vendored signatures type the parameters example 116's untyped calls came from (`QueryParser#_normalize_params`, `Request::Helpers#split_header`, `Multipart::Parser.parse_boundary`/`#initialize`/`#handle_dummy_encoding`/`#handle_empty_content!`, `Rackup::Handler.get`/`[]`); a signature is added only where MRI's calls in the example agree with it, and the example still equals MRI.

**rack 3 signatures, first batch** (#105 step 2; amends decision 160's `sig/gems/rack`, `sig/gems/rackup`; 2026-11-13). *See also decisions 175, 457.*

`RUGAROO_GEM_WARNINGS=1 RUGAROO_UNTYPED_WHY=1 rugaroo gen examples/116_cuba_web/main.rb` names each dynamic call's untyped root. The largest were rack's `QueryParser#_normalize_params(params)` (17 calls), the multipart parser's `env`, `content_type`, `boundary`, `io` and `name` parameters, and `split_header(value)`.

- **Added** (from rack 3.2.7's source): `QueryParser#_normalize_params: (Rack::QueryParser::Params[untyped], String?, untyped, Integer) -> untyped` (params is always a `make_params` Hash; a nested one read back out of it converts where it lands); `split_header: (String?) -> Array[String]`; `Multipart::Parser.parse_boundary: (String?) -> String?`, `#initialize: (String, untyped, Integer, Rack::QueryParser) -> void`, `#handle_dummy_encoding: (String, String) -> [String, String]`, `#handle_empty_content!: (String?) -> void`; `Rackup::Handler.get`/`[]: (String | Symbol) -> untyped`.
- **Tried and left out, with the reason:** `Multipart::Parser.parse(io, content_length, content_type, tmpfile, bufsize, qp)` typed `(untyped, Integer?, String?, untyped, Integer, Rack::QueryParser)` made the example's form POST answer 500 instead of 201: one argument does not fit at run time, and gem code converts where it lands (decision 172), raising TypeError. `Multipart.parse_multipart`/`extract_multipart` likewise (`extract_multipart` is called with `self` from `Request::Helpers`).
- **Measured** (example 116, `RUGAROO_NO_INFER_CACHE=1`): dynamic-call warnings 177 → 133, `rbDyn` dispatchers 55 → 49, `rbAs[` casts 786 → 789. Output == MRI.
- **Still untyped by design:** a Rack app's `call(env)` and the `env` Hash's values; Cuba's `match(matcher)` (a String, Symbol, Regexp, Proc or boolean).

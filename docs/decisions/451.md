# Decision 451

**Rule:** A `class` or `module` statement inside a block (or inside a def, which only ruby/spec's `it` rewrite produces) in program code is declared at compile time, once, in the constant scope where it is written; its body may only declare (defs, `attr_*`, `include`/`extend`/`prepend`, visibility, constants, aliases, nested classes), may add methods to an existing class but not replace one, and the statement's value is its last def's name or nil.

**Class statements in blocks** (#80; amends decision 145; 2026-11-13). *See also decisions 127, 145, 459.*

MRI runs `class Foo ... end` inside a block when the block runs. rugaroo's closed world needs every class before it generates Go, and `collect` only looked at the top level and class bodies, so `[1].each { class Foo; end }` was "unsupported syntax: ClassNode" (83 ruby/spec `core` examples, where `it` blocks declare fixture classes).

- **Where.** `scanAnon` (decision 145's walk for `Class.new` literals) now counts blocks and def bodies it descends into (`inBlockScan`); a `class`/`module` statement it reaches there in a non-gem file goes to `hoistClass`, which checks the body and collects it with `collectClass`/`collectModule` in the scan's lexical scope. A statement in a loop or a block run twice is one class, as `Class.new`'s literal is. Gem code is untouched (a gem's conditional `class X ... end unless defined?(X)` keeps its rules).
- **Only declarations.** A body statement that runs code (`puts`, a method call other than the declaring ones) is a compile error: hoisting would run it at the wrong time. The check reaches into nested `class`/`module`/`class << x` bodies, which are hoisted with their parent (ruby/spec's `base_label_spec` crashed at load before it did). A def replacing a method the class already defines is one too: MRI would use the old method until the block runs.
- **Value.** The statement compiles to its body's last def's name (MRI's value of `class X; def z; end; end` is `:z`), else nil.
- **Known difference from MRI:** before the block runs, MRI's `defined?(Foo)` is nil and `Foo` raises NameError; in rugaroo the class exists from the start. A later top-level reopening that replaces a hoisted method is not refused.
- **ruby/spec `core`:** MEASUREMENT.
- **Proof:** `testdata/test/object_test.rb` `ObjectHoistTests` (a class and a module declared in a block, a block's value, a module included by a hoisted reopening) against MRI; `testdata/errors/objects.txtar` `class_in_block_replaces`, `class_in_block_runs_code`; example 138.
